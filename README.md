## Setup & Installation Guide

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/LRC-source/artisanflow.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd artisanflow
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Environment Configuration:**
   Copy `.env.example` to `.env` and inject your personal API keys and database credentials. *(Never commit your `.env` file to version control).*
5. **Start the development server:**
   ```bash
   npm run dev
   # or
   node server.js
   ```
